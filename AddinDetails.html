MultiSolidPartEnhancements (MSPE)

Add-in help · Version 3.0.1.3 · Body-level materials, mass, hatching, and material leaders for multi-body parts in Autodesk Inventor

How body materials work

Inventor assigns one material to an entire part. MSPE adds a material to each solid body, so one multi-body part can hold, for example, a plywood carcass, solid wood face frame, and MDF panels.

  • Each solid body stores its material by name, separately for every model state
  • A body set to By Part follows the part material, which is the default for every body
  • The body's appearance changes to match its material, so overrides are visible in the model
  • Inventor's own part material, iProperties, and Physical mass still reflect the part material only
  • MSPE commands read the body materials for mass, reports, hatching, and leaders

Body materials come from the material library set in the active project (Projects › Materials). A body material that is missing from that library is handled by the session remap.

NoteParts in a library location (Content Center and project library folders) are read but never changed. Commands skip them without a message unless debug mode is on.

Common workflows

Assign body materials and get a part mass

  1. Open the part and activate the model state to edit
  2. Select the bodies that share a material and run Set Body Material; repeat for each material
  3. If other model states need the same materials, run Push Body Materials
  4. Run Get Part Mass to write the BodyMaterialMass iProperty
  5. Save the part

Add a model state

  1. Activate the model state whose body materials the new one should start with, or select it in the browser
  2. Create or copy the model state with Inventor's own commands
  3. MSPE copies the body materials into the new model state (see Model state copy)

Check an assembly

  1. Run Override Report to see part materials and every body override
  2. If materials are missing from the library, run Remap Missing Materials and save the changed parts
  3. Run Get Assembly Mass for the total

Document a drawing

  1. Confirm the drawing standard has a material hatch map (see Hatching)
  2. Run Hatching on the sheet or the whole drawing
  3. Run Create Material Leaders on section views or individual bodies
  4. After model changes, run Update Material Leaders and Hatching again

Move parts to a new material library

  1. Open the top-level assembly with the new library active in the project
  2. Run Remap Missing Materials and choose a replacement for each missing material
  3. Review the pairs with Edit Material Remap and run the remap again if a pair changed
  4. Save the changed parts before closing Inventor; the remap list is not saved

Prompts, picking, and undo

  • List prompts: select an item and click OK; Cancel ends the command unless the command card states otherwise
  • Yes/No prompts: answer as described on each command card
  • Pick loops: commands that ask you to Select a DrawingView or Select a Body keep asking after each pick; press Esc to finish
  • Status bar: long commands show the body, view, or sheet being processed in Inventor's status bar
  • Undo: each command is one entry in Inventor's undo list; pick loops add one entry per pick

Missing materials and the session remap

When a part or body material is missing from the active material library, MSPE asks for a replacement:

  • The prompt reads Select A Material to replace material: "[missing name]" and lists every library material
  • Your choice is saved in a remap list for the rest of the Inventor session and reused without asking again
  • Clicking Cancel declines that material; the command falls back to the part material for those bodies, and other commands do not ask again this session
  • Any command that reads body materials can show this prompt, including mass, reports, hatching, and leaders
  • Remap Missing Materials writes the replacements into the parts; the other commands only use them for their own result
  • Edit Material Remap changes or deletes pairs and clears the declined list
Watch outThe remap list lives only in memory. Closing Inventor clears it, along with the declined list.

Errors and logs

  • If a command fails, a message shows the error details, then a second message reads Reverting to last Status or Aborting; the command's changes are rolled back
  • Each Inventor session writes a log to %TEMP%\MultiSolidBodyPartEnhancements_Logs\, named by the session start date and time
  • Send the error message (a screenshot works) and the log file to the add-in developer when reporting a problem

About, Addin Details, and debug mode

About

  1. Click About on the MSPE panel
  2. The message shows the add-in version and Inventor version
  3. Click Yes to turn debug mode on; No or Cancel turns it off

Debug mode adds detail to the session log and shows a message when a part is skipped because of its library location. It stays on until you turn it off or close Inventor.

Watch outCreate Material Leaders also sets debug mode: holding Shift when you click it turns debug mode on, and clicking it without Shift turns debug mode off.

Addin Details

Opens this page in your web browser. When the online copy is unreachable, the copy installed with the add-in opens instead, which may be older.

For add-in developers

Other add-ins and iLogic rules can read body materials through the add-in's automation object (ApplicationAddIn.Automation). It exposes MSPEgetBodyMaterial(SurfaceBody) As MaterialAsset, which returns the body material for the active model state, or the part material for a By Part body.

Version notes

  • Version 3.0 and later run on .NET 10, which Inventor 2025.5, 2026.4, and later releases use
  • Body materials saved by versions before 2.0 are no longer converted; re-assign those bodies

    Set Body Material

    Assigns one material to one or more solid bodies, in the active model state or in all model states.

    Part › right-click menu on selected solid bodies

    Before you start

    • The part is in an editable location, not a library or Content Center folder
    • The material exists in the project's active material library
    • The model state to change is active

    How to run it

    1. Select one or more solid bodies in the browser's Solid Bodies folder or in the graphics window
    2. Right-click and choose Set Body Material
    3. If the part has more than one model state, answer Would you like to set the material for all ModelStates in each of the selected solid bodies?
      • Yes applies the material to every model state
      • No applies it to the active model state only
    4. In Select A Material For the selected Body, pick a material and click OK; pick By Part to remove the override

    Results

    • Every selected body receives the same material
    • Body appearance changes to the material's appearance; By Part returns the body to the part appearance
    • Inventor's part material and mass do not change; run Get Part Mass for the body-based mass
    • One undo step covers all selected bodies
    Watch outClicking Cancel in the material list sets the selected bodies to By Part, which removes their existing overrides. Use Undo to restore them.
    NoteThe menu item appears only when every selected item is a solid body. Remove surface bodies, faces, and features from the selection if it is missing.
    NoteIn an assembly, a Set Body Material item also appears on selected bodies but only shows Not Programmed yet. Open the part to set body materials.

    Push Body Materials

    Copies every body material in the active model state to all other model states in the part.

    Part › 3D Model tab › MSPE panel

    Before you start

    • The part has more than one model state
    • The model state with the correct body materials is active

    How to run it

    1. Activate the source model state
    2. Click Push Body Materials
    3. Read the confirmation, which names the part and the source model state, and click Yes to continue or No to stop

    Results

    • Every solid body gets its current material in every model state, including bodies set to By Part
    • One undo step: Push BodyMaterial Overrides
    Watch outOverrides that differ between model states are replaced. A body that is By Part in the active model state becomes By Part in all of them.

    Get Part Mass

    Calculates the part mass from each body's material and stores it in a custom iProperty.

    Part › 3D Model tab › MSPE panel

    Before you start

    • Body materials are assigned with Set Body Material
    • Every material used has a density in its physical properties

    How to run it

    1. Click Get Part Mass
    2. A message titled [part name] Mass: shows the total, followed by an Overridden Bodies: list of each body and its material
    3. Click OK

    Results

    • Custom iProperty BodyMaterialMass is created or updated as text, for example 48.27 lbmass
    • The value uses the part's mass units from Document Settings, rounded to two decimals
    • Mass is each solid body's volume times its material density; surface bodies are excluded
    • Any mass override entered in iProperties › Physical is cleared
    • One undo step: Mass Update From BodyMaterial
    NoteThe iProperty does not update on its own. Run the command again after changing geometry or body materials, and before the part is used in a title block or BOM.
    Watch outA material without density shows [material] does not have Density. and contributes zero mass. Correct the material in the library and run the command again.

    Model State Copy (automatic)

    Carries body materials into new and copied model states, and keeps them when model states are renamed.

    Part › runs automatically; no button

    How it works

    1. Activate the model state to copy from, or select it in the browser
    2. Create a new model state or use Inventor's Copy command on a model state
    3. The new model state starts with the same body materials as the source

    Results

    • Each model state receives a hidden unique ID, so renaming a model state keeps its body materials
    • The copy merges with Inventor's create step in the undo list
    Watch outModel states added through Edit via Spreadsheet do not receive copied body materials. Assign them with Set Body Material or Push Body Materials.

    Override Report

    Lists the part materials used in the assembly and every body material override, in Notepad.

    Assembly › Assemble tab › MSPE panel

    How to run it

    1. Open the assembly and click Override Report
    2. Answer any missing material prompts
    3. Notepad opens with the report

    Results

    • Inventor Materials used in this model: each part material in use
    • BodyMaterial Overrides: each part with overrides, followed by its bodies as Body name - Material
    • Includes parts at every subassembly level that have at least one unsuppressed occurrence
    • Lists only solid bodies with volume; By Part bodies are omitted
    • Materials in the model are not changed
    NoteThe report is a temporary text file. Use File › Save As in Notepad to keep it. If Notepad does not open, the same information appears in two message boxes.

    Get Assembly Mass

    Totals the body-material mass of every unsuppressed part occurrence in the assembly.

    Assembly › Assemble tab › MSPE panel

    How to run it

    1. Click Get Assembly Mass
    2. Answer any missing material prompts
    3. A message shows Total unsuppressed mass: with the value and units

    Results

    • Each part's body-material mass is multiplied by its number of unsuppressed occurrences, at every subassembly level
    • The total uses the assembly's mass units, rounded to two decimals
    • No iProperty is written; part BodyMaterialMass values are not updated
    Watch outOccurrences set to Reference or Phantom BOM structure are counted. Suppress them first if they should be excluded.

    Remap Missing Materials

    Finds part and body materials that are missing from the active library and replaces them in the parts.

    Assembly › Assemble tab › MSPE panel

    Before you start

    • The project's active material library is the one the parts should use
    • The parts are in editable locations and checked out if you use Vault

    How to run it

    1. Open the top-level assembly and click Remap Missing Materials
    2. For each missing material, answer Select A Material to replace material: "[missing name]"
      • Pick a replacement and click OK to use it everywhere that material appears
      • Click Cancel to skip that material for this run
    3. Save the changed parts

    Options

    • Hold Shift while clicking the button to clear the session remap and declined lists first, so every missing material prompts again

    Results

    • Part materials that are missing are replaced with the chosen library material; an old local copy with a conflicting definition is renamed with _was_replaced
    • Body overrides that are missing are replaced in the active model state of each part
    • Materials already in the session remap are applied without prompting
    • Materials declined earlier in the session are asked again once per run
    • One undo step: Remapped Missing Materials; nothing is added to the undo list if no material changed
    • Parts in library locations and parts with only suppressed occurrences are skipped
    NoteReview or change the pairs afterward with Edit Material Remap.

    Hatching

    Sets each body's hatch pattern in section views from its body material, using the drawing standard's material hatch map.

    Drawing › Annotate tab › MSPE panel

    Before you start

    • The active drawing standard has material-to-pattern pairs on the Material Hatch Pattern Defaults tab of the Style and Standard Editor
    • That standard is saved to the style library, since MSPE reads standard.xml in the project's Design Data folder
    • Hatch map names match the material names in the library exactly
    • Views to update have hatching turned on

    How to run it

    1. Click Hatching
    2. If prompted that the drawing standard is Not up to date, click Yes to update it from the library; No ends the command
    3. In For how many views would you like to update hatching?, choose one option:
      • Single View: pick views at Select a DrawingView, then press Esc
      • Entire Sheet (default): every view on the active sheet
      • Entire Drawing: every view on every sheet, after updating the drawing if needed
    4. Review any messages at the end

    Results

    • Regions whose pattern does not match the map are changed
    • Override bodies get the mapped pattern at 45° with By Material turned off
    • By Part bodies get the mapped pattern with By Material turned on
    • Suppressed views and views with hatching off are skipped
    • The following Materials are not mapped to Hatch patterns in the Active Drawing Standard lists materials to add to the hatch map
    • Bad Material Overrides lists bodies whose override could not be resolved, as Override on Solid: [body] in Part: [part]
    • Undo: one step per picked view, or one step per sheet
    Watch outMSPE reads the hatch map once per Inventor session, from the standard of the first drawing that runs a drawing command. A drawing that uses a different standard ends Hatching without a message, and the leader commands report that the drawing style is not up to date. Restart Inventor to work in that drawing.
    Watch outIn Single View, picking a view with hatching turned off ends the pick loop.
    NoteMap errors read Could not build Hatch-Material Map [Style Name Not Found] or [HatchMap Is Empty]. Check that the standard is saved to the style library with a hatch map.

    Create Material Leaders

    Adds a leader naming each body's material, for a single picked body or every hatched body in a view.

    Drawing › Annotate tab › MSPE panel

    Before you start

    • For Entire View, the view is a section view with hatching turned on
    • For hatch updates at the same time, the drawing standard meets the Hatching requirements; leaders still work without them

    How to run it

    1. Click Create Material Leaders
    2. Close any hatch map or drawing style message; the command continues without hatching
    3. In For how would you like to create material leaders?, choose one option:
      • Single Body (default): at Select a Body, click an edge of the body; the leader attaches to the midpoint of that edge
      • Entire View: at Select a DrawingView, click a view; each hatched body gets a leader on its longest visible edge
    4. Keep picking, then press Esc to finish
    5. Drag leader text to its final position

    Options

    • Hold Shift while clicking the button to run in debug mode; picks are then not grouped into undo steps or rolled back on error

    Results

    • By Part bodies get a bold leader linked to the part's Material iProperty, which updates on its own
    • Override bodies get the material name as plain text; use Update Material Leaders after changes
    • Leaders are placed up and to the left of the attach point
    • A body that already has an MSPE leader on one of its edges gets its text updated instead of a second leader
    • The picked body's hatch is also updated, when the hatch map is available
    • One undo step per pick
    NoteLeaders are tagged so the update command can find them. Leaders you draw by hand are never changed by MSPE.

    Update Material Leaders

    Refreshes the text of leaders made by Create Material Leaders after body materials change.

    Drawing › Annotate tab › MSPE panel

    How to run it

    1. Click Update Material Leaders
    2. Close any hatch map or drawing style message; leader updates continue
    3. In For how many views would you like to update material leaders?, choose one option:
      • Single View: pick views at Select a DrawingView, then press Esc
      • Entire Sheet (default): the active sheet
      • Entire Drawing: every sheet, after updating the drawing if needed

    Results

    • Each MSPE leader attached to a model edge is matched to the body it touches, and its text is updated to that body's material
    • A leader moved to a different body takes on that body's material
    • Leaders not attached to an edge, and leaders drawn by hand, are skipped
    • No new leaders are added and hatching is not changed
    NoteSingle View updates every MSPE leader on the sheet that holds the picked view.

    Edit Material Remap

    Shows the session's missing-material remap pairs so you can change or delete them, and clears declined materials.

    Part › 3D Model tab › MSPE panel · Assembly › Assemble tab › MSPE slide-out · Drawing › Annotate tab › MSPE slide-out

    Before you start

    • At least one material has been remapped or declined this session (see session remap); otherwise the command shows No materials have been remapped or declined in this session.

    How to run it

    1. Click Edit Material Remap
    2. The window lists each pair: Missing Material and Remapped To
    3. To change a pair, click its Remapped To cell and pick a library material from the drop-down
    4. To delete pairs, select the rows and click Delete Selected or press Delete
    5. To be asked again about materials you declined, click Clear Declined (n); hover over it to see the declined names
    6. Click OK to save the list, or Cancel to discard the edits

    Results

    • Later commands use the edited pairs
    • Deleted pairs prompt again the next time that material is found
    • Parts already changed by Remap Missing Materials keep their new materials; run it again only for materials that are still missing
    NoteA pair whose replacement is no longer in the active library appears with a blank Remapped To cell. OK reports any blank rows; pick a material or delete the row.
    Watch outClear Declined takes effect immediately, even if you then click Cancel.
